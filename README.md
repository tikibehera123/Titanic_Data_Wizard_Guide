## 🚢 Overview

The Titanic Data Wizard Guide is an educational resource designed to help data science beginners and students understand the critical steps of data preprocessing. Using the famous Titanic dataset as an example, the application provides:

- Step-by-step guidance on data cleaning techniques
- Detailed instructions for feature engineering
- Code examples in Python with pandas
- Visual and interactive learning experience

## ✨ Features

- **Interactive Tutorial Steps**: Navigate through logical progression of data preprocessing
- **Code Snippets**: Copy-ready Python code examples for each step
- **Responsive Design**: Seamlessly works across desktop and mobile devices
- **Clear Explanations**: Detailed rationale behind each data cleaning and feature engineering decision

## 📚 Tutorial Content

The application covers the following key topics:

1. **Introduction to the Titanic Dataset**
2. **Initial Data Exploration**
3. **Data Cleaning Strategies**
4. **Handling Missing Values**
5. **Feature Engineering Techniques**
6. **Feature Transformation**
7. **Final Data Preparation**
8. **Machine Learning Integration**

## 🛠️ Technical Details

This project is built with modern web technologies:

- **Frontend Framework**: React with TypeScript
- **Styling**: Tailwind CSS with custom maritime theme
- **UI Components**: shadcn/ui component library
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js & npm - [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating)

### Local Development

```bash
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to the project directory
cd titanic-data-wizard-guide

# Install dependencies
npm install

# Start the development server
npm run dev
```

The application will be available at `http://localhost:8080`.
